# Contributing to EtherOS Bootloader

Thank you for your interest in contributing to the EtherOS Bootloader project!

## How to Contribute

### Reporting Issues

If you find a bug or have a suggestion:
1. Check if the issue already exists in the issue tracker
2. If not, create a new issue with a clear title and description
3. Include steps to reproduce (for bugs)
4. Specify your VM environment and configuration

### Pull Requests

1. Fork the repository
2. Create a new branch for your feature: `git checkout -b feature-name`
3. Make your changes
4. Test your changes in a virtual machine
5. Commit with clear, descriptive messages
6. Push to your fork
7. Create a pull request

### Development Guidelines

- **Always test in a VM**: Never test on physical hardware
- Keep changes minimal and focused
- Document new features in README.md
- Follow existing code style
- Add comments for complex logic

### Testing

Before submitting a pull request:
1. Test the installation script: `./install.sh`
2. Verify all generated files are correct
3. Test in multiple VM environments if possible
4. Check that documentation is up to date

## Code of Conduct

- Be respectful and constructive
- Help others learn and grow
- Focus on what is best for the project

## Questions?

If you have questions, feel free to:
- Open an issue with the "question" label
- Reach out to the maintainers

Thank you for contributing!
